# This repo: the donedonedone setup itself

This repo has no `vault/` and doesn't need one, so the Director protocol in the root
CLAUDE.md (the global copy install.sh ships) does not run here. One part of it still
applies: grill every enhancement before writing code. Run the grill skill's method as a
conversation with the human, one question at a time, and build only once it stops.
Bug fixes get the scaled-down grill: one confirming question on the expected behavior
and what must not change.
